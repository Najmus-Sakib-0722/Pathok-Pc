# Pathok

বাংলা ই-বুক / লাইব্রেরি অ্যান্ড্রয়েড অ্যাপ।

**বর্তমান অবস্থা:** WebView-ভিত্তিক (`app/src/main/assets/index.html` + Firebase JS SDK)।
**লক্ষ্য:** ধাপে ধাপে সম্পূর্ণ নেটিভ Kotlin + Jetpack Compose অ্যাপে রূপান্তর, ডিজাইন অবিকল রেখে।

## প্রজেক্ট কনটেক্সট ফাইল
- `CLAUDE.md` — Claude Code-এর জন্য প্রজেক্ট নির্দেশনা (স্ট্যাক, কনভেনশন, নিয়ম)
- `PROGRESS.md` — এখন পর্যন্ত কী হয়েছে, পরে কী করতে হবে (প্রতি সেশনের শেষে আপডেট করো)

## Setup
1. Android Studio-তে `Open` → এই রিপোর ফোল্ডার সিলেক্ট করো
2. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করো
3. (নেটিভ Firebase SDK পর্যায়ে গেলে) Firebase Console থেকে `google-services.json` ডাউনলোড করে `app/` ফোল্ডারে বসাও — এই ফাইলটা `.gitignore`-এ আছে, তাই GitHub-এ যাবে না, প্রতিটা মেশিনে আলাদাভাবে বসাতে হবে
4. ডিভাইস/এমুলেটরে Run করো
